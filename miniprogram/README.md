# Мини-программа WeChat: страница визита

Для принимающей стороны — менеджера компании, куда едет делегация. Нативный код WeChat (WXML, WXSS, JS)
без сборщика: что лежит здесь, то и загружается в WeChat.

| Вкладка | Файлы | Что на ней |
| --- | --- | --- |
| 概览 Обзор | `pages/visit/` | где группа, информация и программа визита, подтвердить, предложить другое время, координатор, подписка на уведомления, «поделиться с коллегами», 中文/EN |
| 代表团 Делегация | `pages/delegation/` | 18 гостей с фильтром по отраслям, без телефонов; список для охраны в Excel |
| 问题与资料 Вопросы и материалы | `pages/prep/` | вопросы делегатов на китайском; загрузка презентации на проверку координатору |
| 访问后 После визита | `pages/after/` | оценка группы, запросы на продолжение, контакты с согласия, ответ через координатора |
| 微信支付 Оплата | `pages/pay/` | заказ и WeChat Pay; открывается ссылкой `/pages/pay/index?o=<id>` |

- `utils/api.js` — вход (`wx.login` → сервер), визит, загрузка и скачивание файлов, «поделиться».
- `utils/i18n.js` — тексты на китайском и английском. `utils/format.js` — даты, размеры, суммы.
- `config.js` — адрес сервера; при загрузке через `tools/mp-ci.mjs` подставляется `MP_API_BASE`.
- `assets/` — иконки вкладок и значки (пересобрать: `node tools/mp-icons.mjs`).

Приглашение приходит параметром `i` в ссылке или `scene` в QR-коде мини-программы — его создаёт координатор
(`POST /api/admin/visits/:id/invites`, картинка — `GET /api/admin/invites/:code/qr.png`).

## Проверить

- Без WeChat: `node tools/mp-check.mjs` из корня — статика и сценарии страниц против сервера в режиме mock.
- Картинки экранов из настоящего WXML и данных сценариев: `node tools/mp-shots.mjs` →
  `design/previews/miniprogram/` и лист `design/previews/_мини-программа.jpg` (приближение: WeChat рисует сам).
- В WeChat DevTools (Windows/Mac): открыть папку `miniprogram/`, в соседнем терминале `npm run dev --prefix server`.
- На телефоне: QR предпросмотра — `node tools/mp-ci.mjs preview --query i=<код>` или GitHub Actions
  «Мини-программа WeChat» → preview; QR лежит в артефактах запуска.
