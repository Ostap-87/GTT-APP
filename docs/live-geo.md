# Живая геопозиция и SOS — контракт коннектора

Решение пользователя 27.10.2026: «Координатор видит на карте, кто отстал от группы. Кнопка SOS отправляет точку и сразу
набирает координатора… только с отдельного согласия участника, это персональные данные… тут можно просто заготовку для
коннектора сделать, пока не подключать ничего».

Сейчас (шаг 1) сделана только заготовка: в приложении есть коннектор `mobile/src/data/live-geo.ts` с одним интерфейсом и
двумя исполнениями. Пока переменная `EXPO_PUBLIC_GEO_URL` пустая, работает демо-коннектор: **точки никуда не уходят**.
Координатор видит SOS и точку участника только на этом же телефоне, остальные участники на карте группы вымышленные.
Когда появится сервер (шаг 2, в России — 152-ФЗ), нужно задать `EXPO_PUBLIC_GEO_URL` (и при желании `EXPO_PUBLIC_GEO_TOKEN`).
Тогда приложение пойдёт по контракту ниже, и правки экранов не понадобятся.

## Правила (их проверяет и сервер)

- **Согласие** — отдельное, по умолчанию выключено (экран «Геопозиция для координатора»). Выключил — сервер удаляет точку.
- **Только в дни поездки** и пока приложение открыто: позиция раз в 3 минуты (`FIX_EVERY_MS`). Фонового слежения нет.
  Для него понадобятся отдельная сборка (не Expo Go), фоновое разрешение и новое решение пользователя.
- **Хранится последняя точка**, истории перемещений нет. После поездки точки удаляются.
- **Кто видит:** только координатор этой поездки. Делегаты, компании и агенты — нет.
- **SOS** отправляет точку и без постоянного согласия, но только по нажатию. Кнопку нужно удерживать 1,5 секунды.
  Звонок координатору набирает телефон, сервер для него не нужен.
- **Отстал** — дальше 300 м от точки сбора (`LAG_M`). Точка сбора — визит дня или отель. **Устарела** — не обновлялась
  15 минут (`STALE_MIN`).

## API (JSON, заголовок `x-app-token` — если задан `EXPO_PUBLIC_GEO_TOKEN`)

| Метод | Путь | Тело / параметры | Ответ |
| --- | --- | --- | --- |
| POST | `/api/geo/consent` | `{ trip, member, on }` | `200 {}`; `on: false` — удалить последнюю точку |
| POST | `/api/geo/fix` | `{ trip, member, lat, lng, acc?, at }` | `200 {}`; `403`, если нет согласия или день вне поездки |
| POST | `/api/geo/sos` | `{ trip, member, fix: { lat, lng, acc?, at } \| null }` | `200 {}` и уведомление координатору (push, WeCom, Telegram) |
| GET | `/api/geo/group?trip=` | — | `200 { members: [{ id, consent, fix: { lat, lng, acc?, at } \| null }] }`, только координатору |

- **Координаты** — WGS-84, как отдаёт GPS телефона. Если сервер хранит GCJ-02 (Amap), пересчёт есть в `server/src/amap/coords.js`.
- **Ошибки сети:** приложение считает их «не отправлено». SOS при этом всё равно идёт звонком.

## Где в приложении

- **Делегат:** «Помощь» → SOS вверху (`app/help.tsx`); «Геопозиция для координатора» (`app/geo-consent.tsx`).
- **Координатор:** «Пульт» → «Где группа» и SOS первым в «Требует внимания»; экран «Где группа» (`app/group-map.tsx`):
  офлайн-карта города, отставшие, устаревшие точки, кто без согласия.
- **Состояние:** `state/geo.tsx` (согласие, последняя точка, SOS; демо-точки группы).
