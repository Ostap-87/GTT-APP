# WeChat: мини-программа и интеграции

**Статус (15.10.2026): код готов, ждёт аккаунта мини-программы.** По решению пользователя сделано всё, что
можно сделать в облаке; дальше нужны регистрация, ключи и сервер (чек-лист ниже).

## Что сделано

| Что | Где | Как проверено |
| --- | --- | --- |
| Мини-программа: 4 вкладки принимающей стороны по дизайну (`R-H-*`) + оплата, китайский и английский | [`miniprogram/`](../miniprogram/README.md) | `node tools/mp-check.mjs`: статика + 12 сценариев страниц против сервера |
| Вход через WeChat (`wx.login` → `code2session`), приглашения ссылкой и QR-кодом мини-программы | `server/src/app.js`, `wechat/client.js` | тесты API |
| Подписочные уведомления: «группа выехала», «перенос», «новый запрос» | `server/src/events.js`, `config/subscribe-templates.json` | тесты API (mock WeChat) |
| Карточки «поделиться» в чаты: коллеги получают роль только для просмотра | `pages/*/index.js`, `/api/wx/visits/:id/share` | сценарий «коллега» |
| WeChat Pay (API v3, JSAPI): заказ, подпись, проверка и расшифровка уведомления | `server/src/wechat/pay.js` | тесты на сгенерированных ключах |
| Бот WeCom: сообщения команде — вход компании, перенос, файл, ответ, оплата | `server/src/wecom.js` | тесты |
| Загрузка версий и QR предпросмотра | `tools/mp-ci.mjs`, GitHub Actions «Мини-программа WeChat» | доходит до серверов WeChat; с настоящим AppID — после регистрации |
| Список гостей для охраны в Excel, без паспортов | `server/src/xlsx.js` | файл открывается как .xlsx |

Без настоящего аккаунта не проверено: вход на реальном телефоне, доставка уведомлений, оплата. Это первый
шаг после регистрации — QR предпросмотра и тест на своём WeChat.

## Как это работает

1. Координатор заводит визит (`PUT /api/admin/visits/<id>`) и создаёт приглашение — QR-код мини-программы.
2. Менеджер компании сканирует QR → открывается страница визита на китайском, без регистрации.
3. Он подтверждает время или предлагает другое, загружает презентацию, скачивает список для охраны,
   пересылает карточку коллегам. Команде GTT в WeCom приходит сообщение о каждом действии.
4. В день визита координатор отмечает «группа выехала» — компании приходит уведомление WeChat.
5. После визита компания видит оценку группы и запросы; контакты — только тех, кто разрешил.

## Чек-лист: что нужно от вас

1. **Аккаунт мини-программы** на mp.weixin.qq.com на компанию (китайскую или зарубежную) и верификация.
   Требования для иностранной компании проверить при регистрации. Вход — по QR своим WeChat.
2. **В кабинете** (开发管理 → 开发设置):
   - **AppID.** Его можно написать в чат: он не секретный.
   - **AppSecret.** Положить в переменные сервера.
   - **Ключ загрузки кода.** Сохранить в секрет GitHub `MP_UPLOAD_KEY`. Белый список IP для загрузки выключить.
3. **Сервер** с HTTPS-доменом, быстро доступный из Китая (Гонконг или Китай). Домен внести в 服务器域名 →
   request, uploadFile, downloadFile. Для материкового Китая нужна регистрация 备案.
4. **Шаблоны уведомлений** (订阅消息): выбрать 2–3 шаблона и прислать их ID и поля. Впишу их в
   `server/config/subscribe-templates.json`.
5. **Бот WeCom:** создать рабочую группу GTT в 企业微信 → «添加群机器人». Ключ вебхука положить в переменную сервера.
6. **WeChat Pay (по желанию):** торговый счёт (商户号), обычно на китайскую компанию, привязать к AppID.
   Ключи — только в переменных сервера.
7. **Проверка:** запустить Actions → «Мини-программа WeChat» → preview и отсканировать QR своим WeChat.
   Потом upload, модерация (1–7 дней) и публикация в кабинете.

Секреты — AppSecret, ключ загрузки, ключи WeChat Pay, ключ вебхука WeCom — никогда не присылайте в чат.
Репозиторий публичный, поэтому в нём их тоже нет.
