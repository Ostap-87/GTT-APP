# Решения по приложению GTT

Журнал договорённостей с пользователем. Новые записи — сверху. «Решение» — сказал пользователь;
«Предложение» — ждёт его «да».

## 15.10.2026

- **Решение.** Всё по проекту приложения — документы, инструкции, дизайн — хранится в репозитории
  `Ostap-87/GTT-APP`.
- **Решение.** Три пользовательских сценария: делегат, координатор, принимающая сторона. Полный функционал —
  у координатора: он видит сценарии и делегата, и принимающей стороны («Смотреть как делегат / как JD.com»).
  Исходные варианты интерфейса A, B и C сведены в эти три сценария (холст, страница «Сценарии по ролям»).
- **Решение.** Приложение нужно и для администрирования, и для удобства участников; iOS и Android.
- **Предложение.** Принимающая сторона работает по ссылке в WeChat или браузере, без установки,
  на китайском и английском; видит только свой визит и не видит телефонов делегатов.
- **Предложение.** React Native + Expo, сервер Node.js + PostgreSQL на VPS reg.ru, каталог из сборки сайта
  (подробно — [architecture.md](architecture.md)).
- **Вопрос пользователя.** Мини-программа WeChat и интеграции — возможны, вынесены во второй этап
  ([wechat-mini-program.md](wechat-mini-program.md)).
