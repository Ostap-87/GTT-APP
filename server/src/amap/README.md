# Модуль «Рядом»: Amap + перевод на язык делегата

Ближайшие аптеки, фруктовые лавки, супермаркеты и магазины у дома по картам **Amap (高德地图)** — уже переведённые
на русский, английский, казахский или узбекский, с китайским оригиналом для таксиста. Решение пользователя 26.10.2026:
«сделай встраиваемый модуль для Amap, чтобы мы могли быстро его интегрировать».

```
телефон (GPS, WGS-84) ──▶ сервер GTT /api/nearby ──▶ Amap «搜索POI 2.0» (ответ по-китайски)
                              │  пересчёт координат в GCJ-02, кэш 6 ч, лимит запросов
                              ▼
                         перевод: сети — по словарю приложения, типовые слова — по таблицам,
                         имена — русскими буквами (Палладий) или пиньинем; оригинал остаётся рядом
                              ▼
телефон ◀── «Аптека «Лаобайсин (LBX)» · ул. Наньцзин Дун · 350 м · круглосуточно» + 老百姓大药房(南京东路店)
```

Без ключа модуль работает в **демо-режиме**: вымышленные места вокруг точки (`"source": "demo"`, у каждого `"demo": true`),
приложение показывает плашку «Демо». Так блок можно собрать, показать и проверить до получения ключа.

## Подключить за 15 минут

1. **Аккаунт разработчика Amap** — https://lbs.amap.com («注册» → «控制台»). Нужен китайский номер телефона, проверка
   личности. Для коммерческого приложения — аккаунт компании и «技术服务许可» (лицензия, цена по запросу): с ней
   500 000 поисков в месяц. Бесплатно — 5 000 в месяц, только для некоммерческого использования. Сверх лимита — 30 юаней
   за 10 000 поисков (тарифы — https://lbs.amap.com/upgrade, проверено 26.10.2026).
2. **Ключ** — «应用管理 → 创建新应用 → 添加Key», тип **«Web服务»**. В настройках ключа впишите IP сервера в белый список.
3. **Сервер** — переменные окружения (файл systemd, права 600; в репозиторий и в чат — никогда):
   ```
   AMAP_KEY=…                  # ключ «Web服务»
   NEARBY_APP_TOKEN=…          # любая длинная строка; то же значение — в сборке приложения
   NEARBY_RATE_PER_MIN=30      # запросов в минуту с одного IP (по умолчанию 30)
   ```
4. **Приложение** — при сборке (секреты GitHub / переменные EAS):
   ```
   EXPO_PUBLIC_NEARBY_URL=https://<адрес сервера>
   EXPO_PUBLIC_NEARBY_TOKEN=<тот же NEARBY_APP_TOKEN>
   ```
   Без `EXPO_PUBLIC_NEARBY_URL` блок «Рядом с вами» не показывается — остаются слова для поиска в Amap.
5. **Проверка**: `curl 'https://<сервер>/api/nearby?kind=pharmacy&lat=31.2304&lng=121.4737&lang=ru' -H 'x-app-token: …'`
   → `"source": "amap"`.

## API

`GET /api/nearby?kind=pharmacy&lat=31.2304&lng=121.4737&lang=ru[&radius=1500][&coord=wgs84]`

| Параметр | Что это |
| --- | --- |
| `kind` | `pharmacy` (код Amap 090601 «药房»), `fruit` (поиск «水果», без кафе), `supermarket` (060400), `convenience` (060200); путеводитель: `food` (рестораны 0501–0504), `cafe` (кофейни, чайные, десерты 0505–0509), `sights` (110000 + музеи 1401, 1404, 1406; радиус 5 км), `mall` (060100; 3 км) |
| `lat`, `lng` | где человек; по умолчанию координаты GPS (`coord=wgs84`), для точки из Amap — `coord=gcj02` |
| `lang` | `ru`, `en`, `kk`, `uz` |
| `radius` | метры, по умолчанию 1500 |

Ответ (одно место; демо-режим):

```json
{
  "source": "amap", "cached": false, "kind": "pharmacy", "lang": "ru",
  "items": [{
    "id": "B0FF…", "name": "Аптека «Лаобайсин (LBX)»", "branch": "Дундань", "chain": "laobaixing",
    "type": "Аптека", "address": "р-н Дунчэн, ул. Дундань Бэй, 8", "hours": "круглосуточно", "open24": true,
    "tel": [], "rating": 4.6, "photo": null, "tag": null, "distance": 350, "walkMin": 5,
    "zh": { "name": "老百姓大药房(东单店)", "address": "东城区东单北大街8号", "city": "北京市" },
    "location": { "gcj02": [116.404, 39.9105], "wgs84": [116.3978, 39.9091] },
    "links": { "amap": "https://uri.amap.com/marker?…", "route": "https://uri.amap.com/navigation?…&mode=walk…" }
  }]
}
```

Ошибки: `400 bad_kind | bad_location | out_of_china`, `401 app_token`, `429 too_many`,
`502 amap_unavailable` (Amap не ответил — приложение предлагает слова для поиска в Amap).

## Как переводится

- **Сети** — `data/chains.json` из `mobile/src/data/shops.ts` (`PHARMA`, `FRUIT_CHAINS`): тот же словарь, что видит человек
  в разделе. Добавили сеть в приложение → `python3 tools/amap-data.py --chains-only` (тест сервера проверяет совпадение).
- **Кухни и типы мест** — `data/types-i18n.json`: 91 категория Amap (кухни, кафе, места, ТЦ) на русском, казахском
  и узбекском, английский — официальный из таблицы Amap. Средний чек — поле `cost` (юани на человека).
- **Известные места** (`FAMOUS` в `translate.js`, только для `sights`): 故宫 → «Запретный город (Гугун)», 外滩 → «Набережная
  Вайтань (Бунд)», 长城 → «Великая Китайская стена» и др. — принятые названия вместо транслитерации.
- **Типовые слова** (`translate.js`): аптека, фрукты, супермаркет; район, улица, проспект, переулок, этаж, корпус,
  выход метро, «рядом», «напротив»; часы работы (пн–вс, «круглосуточно»).
- **Имена собственные** — по Палладию (`translit.js`: 同仁堂 → Тунжэньтан, 南京东路 → ул. Наньцзин Дун) для русского
  и казахского; пиньинем, как на табличках улиц, для английского и узбекского. Таблица знаков — `data/pinyin.json`
  (Unicode Unihan, ~15 тыс. знаков, `python3 tools/amap-data.py`); знаки, которые в названиях читаются иначе
  (重庆, 厦门, 银行, 大参林…), — `WORD_READING` и `CHAR_READING`.
- **Машинный перевод** — только запасной путь для меток («可刷医保»): `MT_PROVIDER=yandex` (`MT_KEY` — ключ сервисного
  аккаунта, `MT_FOLDER_ID`) или `deepl` (`MT_KEY`). Названия и адреса им не переводим: «老百姓» он переведёт как «простой
  народ», а на вывеске — Laobaixing. Без настроек метки с иероглифами просто не показываются.

## Встроить в другой сервер

```js
import { createNearby } from './amap/index.js';
const nearby = createNearby({ key: process.env.AMAP_KEY });
// в любом обработчике GET:
const reply = await nearby.search({ kind: 'pharmacy', lat, lng, lang: 'ru' });
```

`createNearby` — без внешних зависимостей (Node.js 20+: `fetch`, `AbortSignal.timeout`). В этом сервере маршрут —
`server/src/app.js` (`/api/nearby`, CORS для веб-версии, лимит запросов). Кэш — в памяти: 6 часов на клетку ~100 м
(срок хранения данных Amap уточнить в договоре на лицензию).

## Файлы

| Файл | Что делает |
| --- | --- |
| `index.js` | `createNearby` (поиск, кэш, демо-режим), `KINDS`, `rateLimiter` |
| `client.js` | запрос к Amap `/v5/place/around`, коды ошибок, `normalize` |
| `coords.js` | WGS-84 ↔ GCJ-02 (сдвиг 100–700 м в Китае), расстояние |
| `translate.js` | названия, адреса, часы на ru / en / kk / uz |
| `translit.js` | иероглифы → пиньинь → Палладий |
| `mt.js` | машинный перевод (Yandex / DeepL) с кэшем, выключен по умолчанию |
| `data/` | `pinyin.json`, `poi-types.json` (категории Amap с английскими названиями), `chains.json` |

Тесты — `server/test/amap.test.js` (`npm test --prefix server`).
